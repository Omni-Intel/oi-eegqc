# v0.4.0 · 采集文件夹上传

[下载 Windows 安装版](https://github.com/Omni-Intel/oi-eegqc/releases/download/v0.4.0/OI-EEGQC-Setup-Windows-x64.exe)

下载并运行安装器即可。

- 新增采集文件夹后台上传，无需登录或配置凭据；文件通过短期签名地址直传对象存储。
- 保留原目录结构，支持取消、失败重试及重启后继续原批次；全部文件成功后写入完成标记。
- 未添加文件、未完成评分或正在评分时，上传入口置灰。
- 修复云端签名清单格式兼容问题，以及打开上传窗口时重复显示历史错误的问题。
- 保持现有评分核心、阈值和窗口标题不变。

上传使用整文件传输；单文件超过 5 GiB 暂不支持，请联系管理员启用分片上传。重试保留原批次编号，失败文件重新传输，已成功文件跳过。

安装包未做代码签名，Windows 可能显示未知发布者提示。
