# v0.4.3 · 离线上传修复

[下载 Windows 安装器](https://github.com/Omni-Intel/oi-eegqc/releases/download/v0.4.3/OI-EEGQC-Setup-Windows-x64.exe)

运行安装器即可覆盖升级，仅提供安装版。

- 上传前检查服务连接，离线时提示联网重试，不再误入编号未确认状态。
- 区分连接失败和请求发出后响应丢失，仅后者需要恢复编号。
- 增加两次确认的“重置上传记录”，仅清理选中文件夹的本地编号、续传状态和历史映射，不删除本地文件或云端数据；下次上传申请新编号。
- 保持原有评分、跨日覆盖及上传进度逻辑。

上传与界面 63 项针对性测试通过。单文件仍限 5 GiB，大文件需要后端支持分片上传。安装包未做代码签名。
