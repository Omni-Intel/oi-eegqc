# v0.4.2 · 跨日覆盖上传

[下载 Windows 安装版](https://github.com/Omni-Intel/oi-eegqc/releases/download/v0.4.2/OI-EEGQC-Setup-Windows-x64.exe)

运行安装器即可覆盖升级。本版仅提供安装器，不提供便携包。

- 每个采集文件夹持久保存上传标识，软件重启、第二天再次上传仍复用。
- 再次上传时，同路径文件覆盖、新文件追加，不删除云端旧文件。
- 上传文件夹内全部普通文件，包括子文件夹中的截图、照片和视频。
- 文件列表按文件夹分组，上传页展示各文件夹的路径、数量、大小和采集标识。
- 只有明确确认“作为新采集上传”才为已关联文件夹开始新的采集批次。
- 保留后台进度、取消和失败续传；评分核心不变。

注意：文件夹身份按本机完整路径保存，移动文件夹或更换电脑不会自动继承关联。覆盖是逐文件进行，并非整个文件夹的原子替换；后端消费者需配合处理再次上传期间旧完成标记的失效，避免读取新旧混合数据。

当前签名接口仅支持普通上传，单文件上限仍为 5 GiB（并非文件夹总大小限制）。更大文件需要管理员启用分片上传接口，不能仅取消客户端检查。

安装包未做代码签名，Windows 可能显示未知发布者提示。
