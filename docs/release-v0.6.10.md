# EEGQC 0.6.10

- 上传面板增加明确的范式选择与数据库存储位置，支持文件、文件夹及主列表导入。视频和 RSVP 使用各自的桶、目录和续传队列。
- 原始数据上传无需先评分；低分、无法评分的文件可一并保存。
- 便携版、安装版启动时自动检查更新，优先内网渠道，默认后台下载；评分或上传期间不自动重启。便携更新保留目录、设置、文件列表和上传队列。
- 增加运行遥测：记录应用形态、版本、范式、失败阶段、异常类型及代码位置，离线保存、联网补传，不发送脑电内容、人员信息或长期密钥。
- 新增博睿康 JellyFish `.float32` 无损记录读取及提供的 65 列设备布局；TRG、ECG、眼电辅助列不参与 EEG 评分。

验证：数据库范式目录、RSVP 实际 COS 上传、界面加载、便携包启动、内网更新清单、便携文件替换与重启、两种应用形态的生产遥测回执。

早期便携版可解压新版完整文件夹替换程序；从本版开始支持原目录内自动更新。安装版运行安装包升级。
