# 评估详情

详情页从评分报告中的窗口证据生成说明，显示相对文件起点的秒数、异常导联、异常类别、占比及本次实际阈值。

- 窗口通过率：通过窗口数 / 全部窗口数。
- 类别异常比例：出现该类别的窗口数 / 全部窗口数；不同类别可重叠，不能相加。
- 导联异常比例：该导联触发任一种异常的窗口数 / 全部窗口数；同窗多原因只计一次。
- 复核区间覆盖：未通过窗口的时间区间取并集后的长度，不重复累加重叠部分，也不等同于精确伪迹时长。
- 削顶平台比例：该窗口该导联合格平台样本 / 有效样本，不是病因概率。

异常明细每页 20 窗，包含仍通过的局部异常窗口。旧缓存打开时从保存的窗口证据重新生成说明；缺少证据时明确提示无法定位。

详情区分检测现象和复核建议，列出未评估维度、频段覆盖限制及停用检测项。算法没有校准的病因概率，因此不提供数值置信度。窗口定位不能推算被试动作次数；可用窗口为零也不能证明全程运动或全程高阻抗。

说明由确定性规则生成，在本地运行。它不改变评分、阈值或上传条件。

## 算法 v3 修订

缺失或非有限样本与数值恒定分别报告。异常窗口保存峰峰值、缺失样本数量、可计算的频谱比、时间/空间离群值和相关性，并显示实测值相对阈值的差距。没有计算的指标保留为空。

极值平台采用局部形态检测，不受同窗更大尖峰遮蔽。普通量化也可能产生平台，因此该形态仅作复核提示，不单独扣分、判窗失败或强制归零。幅度、噪声等独立规则继续评分。`oi-eegqc-score-v3` 使旧评分缓存失效；实际硬件满量程仍须设备参数与原始数字码确认。
