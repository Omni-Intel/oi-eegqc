# EEGQC 0.6.11

支持拖入 ZIP 或包含 ZIP 的文件夹，后台解压并显示进度。重复导入复用已解压文件，原压缩包保持不变。

RSVP 采集包自动识别被试编号、原采集 Session 和范式，并匹配平台现有被试。博睿康无损数据优先评分，EDF 副本保留上传，同一信号的时长只计算一次。

点击上传前自动评分，报告随采集文件保存。上传完成后自动写入平台的现有 Session 和质检统计表；相同被试、范式和原 Session 重复提交不会新增记录。评分暂缺的数据仍可上传，分数和有效时长留空。

界面分别提示上传与入库结果。文件已上传但入库失败时，点击“重试入库”即可继续，不会重新上传已完成的文件。

有效时长采用 EEGQC 可用窗口比例：最终分数达到 60 分时，实际脑电时长乘以可用窗口比例；低于 60 分时为 0。图片呈现有效数量单独保留，不作为脑电有效时长。
