# v0.4.1 · 界面与上传体验优化

[下载 Windows 安装版](https://github.com/Omni-Intel/oi-eegqc/releases/download/v0.4.1/OI-EEGQC-Setup-Windows-x64.exe)

下载并运行安装器即可，支持覆盖升级。本版仅提供安装器，不再构建便携包。

- 统一弹窗、进度条和操作样式，上传页更紧凑，适配小窗口。
- 未开始上传时隐藏空进度和速度；失败原因固定显示，避免被滚动区域截断。
- 移除上传前后的全量文件哈希扫描，改用路径、大小和修改时间进行轻量检查。
- 保留原批次续传、上传结果检查及全部成功后才创建完成标记的保护。
- 评分核心及应用更新安装包的安全校验不变。

单文件超过 5 GiB 暂不支持。相同大小且修改时间不变的文件内容变化无法通过轻量检查检测。

安装包未做代码签名，Windows 可能显示未知发布者提示。
