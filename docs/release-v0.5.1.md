# v0.5.1 · 安装与体积优化

[下载 Windows 安装器](https://github.com/Omni-Intel/oi-eegqc/releases/download/v0.5.1/OI-EEGQC-Setup-Windows-x64.exe)

运行安装器即可覆盖升级，仅提供 Windows x64 安装版。

- 精简桌面端未使用的网页、三维、图表、多媒体等 Qt 运行组件。
- 精简 MNE 演示资源与非评分模块，保留 EDF、BDF 等采集文件读取能力。
- 减少无用 QML 样式、工具和翻译资源。
- 调整安装器压缩策略，缩短构建和安装时间。
- 评分、缓存、上传、更新检查与用户本地配置路径保持不变。

本机验收中，安装包由约 154.1 MiB 降至 89.6 MiB，解包文件数由 3501 降至 742；实际速度会受磁盘和安全软件影响。

已通过 210 项现有测试，并完成打包启动、隔离安装及 128、256、512、1000 Hz 评分验证。新版上传后端联调仍需等待后端部署。

安装包未做代码签名，Windows 可能显示未知发布者提示。
