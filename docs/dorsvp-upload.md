# RSVP 双图 EEG 上传

在 EEGQC 上传窗口中选择 `RSVP双图EEG · DoRSVP-20261011`。
目标位置为 `cos://jianyu-1442740494/DoRSVP/`，地域 `ap-beijing`。
范式列表和上传位置由人员平台数据库提供，重新打开上传窗口可刷新列表。

主界面拖入采集目录或 ZIP，进行 EEG 评分，再上传。
完整 Session 元数据可自动匹配现有被试；上传完成后回写 Session、文件位置、数据量和评分统计。
采集数据的范式代码应明确为 `DoRSVP-20261011`，避免沿用单图 RSVP 的代码。

采集目录的 `session.json` 包含以下字段，值由采集程序填写：

```json
{
  "participant_id": "8位平台被试编号",
  "session_id": "采集程序的Session标识",
  "paradigm_code": "DoRSVP-20261011",
  "started_at": "带时区的ISO 8601采集开始时间",
  "ended_at": "带时区的ISO 8601采集结束时间"
}
```

EEG 文件可放在该目录的 `eeg/` 子目录。
EDF/BDF 使用文件内采样率、单位和通道信息；NPY、float32 使用其配套元数据。
采集导出规范中已有的采样率、物理单位、通道名称和设备信息继续填写真实值。

质检使用通用 EEG 评分和现有设备通道识别。
双图的图片编号、呈现时间和事件映射应保留在原始事件文件中；目前没有双图事件级对齐验收结论。
