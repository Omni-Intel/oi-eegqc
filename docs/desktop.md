# EEGQC 桌面版

Qt / PySide6 原生桌面界面，复用现有 Python 评分核心，完全本地处理。

## Windows 使用

解压 `OI-EEGQC-Windows-x64.zip`，打开文件夹中的 `OI-EEGQC.exe`。
保留整个文件夹（包含 `_internal`），无需另装 Python。当前构建未做代码签名。

多选或拖入 EDF / BDF / NPY 文件，或直接拖入一个或多个文件夹，再点击「评分」。
文件夹会在后台递归扫描子文件夹，自动筛选支持的文件；扫描期间可取消。
「选择文件」「选择文件夹」为两个独立的原生按钮。再次选择会追加，重复路径自动去重。
同名文件显示相对路径以区分。目录链接（含符号链接与 Windows 联接）不会递归进入；
无法访问的目录会跳过并提示。空目录会显示未找到支持的文件。
列表只显示文件名、0–100 质量分数与中文可用性。应用界面的文件名以小写显示，
实际文件名及读取路径不变；系统文件选择器仍显示文件原名。
EDF/BDF 按各自文件头读取实际采样率与单位，不重采样到 250 Hz。
NPY 本身不记录采样率；导入框不再预填 250，必须输入实际值。
支持整数或小数采样率，已测试 64、128、250、256、500、1000、2000 Hz。
可勾选将同一组参数应用于其余数组文件；参数不同的文件应分别确认。
也可为 `sample.npy` 提供同目录 `sample.json`：

```json
{"sfreq": 500, "unit": "uV", "channels_first": true}
```

这三个字段齐全时自动导入；部分字段缺失时仍需确认。采样率还接受
`sampling_rate` 或 `SamplingFrequency` 字段，多个字段必须一致。
每个文件的声明优先于批量共享参数；无效或冲突的参数会提示并跳过该文件。
悬停分数可查看实际采样率和时长。低采样率会限制可检测频段，不能解释为
完整频谱质量已验证；对应提示也显示在分数上。

批量可用比例 = 状态为「可用」的文件数 / 当前列表全部文件数。
「需留意」、不可用、失败及未完成文件均不计入可用数，分母仍包含它们。
这是按文件计数的通过比例，不是按时长加权的可用信号比例。
评分途中同时显示进度；删除或追加文件后重新统计，失败重试不会重复计数。

默认始终使用核心自适应评分，不再提供设置，也不读取旧版固定模式偏好。
文件按顺序在后台评分，单个失败不影响后续；再次点击评分只处理未完成或失败的文件。
评分在独立进程中执行，界面显示准备、读取、检查、评分阶段，以及动态加载条和当前文件耗时；不显示虚假的单文件百分比。
「停止」会终止当前评分进程，保留已完成结果；当前取消的文件可以重新评分。评分中关闭窗口也会取消当前任务。
单文件最多等待 15 分钟（包括进程启动），超时或评分进程异常退出后标记失败并继续队列，允许之后重试。
可多选列表行后按删除键或右键「移除」，也可右键「清空」列表；均不删除磁盘文件。

## 开发与打包

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -e '.[desktop,packaging,dev]'
.venv/Scripts/python -m oi_eegqc.desktop
powershell -ExecutionPolicy Bypass -File scripts/build-desktop.ps1
```

macOS / Linux 可安装相同依赖后运行 `oi-eegqc-desktop`。
二进制需在目标系统运行 `python -m PyInstaller eegqc.spec` 分别构建；
当前交付包仅为 Windows x64，尚未在其他系统验证。

窗口标题为 `Omni-Intelligence EEG Quality Control App`，窗口和可执行文件图标沿用品牌 ICO。
内容区域保留极简列表，不增加圆环或页脚。按钮采用平台原生样式。Qt 使用动态库随包分发；
第三方包元数据与许可证位于 `_internal`，分发时需保留。

窗口启动不加载 NumPy/SciPy/MNE；首次评分时由后台任务按需加载。
首次评分仍需初始化计算依赖。扫描异常会恢复导入控件并允许重试；
退出时先结束当前后台任务，避免运行中的线程被销毁。
异常日志位于系统应用数据目录的 `Omni-Intelligence/EEGQC/logs`，
单个日志最多约 1 MB，保留两个备份，不记录信号数组。
参数文件限制为 64 Ki 字符，避免错误导入巨大的参数文件。
